日期：2026-10-27。基线：`1ec311b`。审查范围为本轮适配的全部未提交源码、类型、测试、交付脚本、依赖、demo 和文档。真机验收按已确认范围后补。

## 已修复问题

以下问题均先用失败的回归用例复现，再修改实现。

| 边界 | 原问题及修复 |
| --- | --- |
| App 系统名包含空白 | 新增目标识别回退没有沿用 App 系统端口的 trim，导致原来可用的宿主被拒绝；恢复相同归一化。 |
| App 页面转发 | 为小程序补充的路由探测会额外读取 App 的 `$scope`；读取异常时中断页面转发。将新增元数据读取限定在小程序，保持原 App 路由及页面类型判定。 |
| 长时间后台后切换 scene | 场景续期保留旧 lastCloseTime，随后重复 onShow 又创建 session／VISIT；前台场景及活动续期清除离开时间，后台换用户和恢复采集仍保留原规则。 |
| 首次 App 显示前恢复采集 | Page.onShow 先到且当时未同意采集，延后执行时仍携带旧关闭快照，漏发当前 PAGE；在真实 App 显示时采用该显示意图的采集状态。 |
| 队列已满 | PAGE 补发失败仍设置去重标记，队列排空后的真实 onShow 被吞；仅在 PAGE 成功入队后去重。 |
| 其他页面卸载 | 页面补发后，卸载非当前实例也会清除去重标记，导致当前 PAGE 重复；根据实际当前页面保留或清除标记。 |
| extraData 与原 query 冲突 | 原 query 值无效或 getter 抛错时，extraData 会填入同名值；原 query 自有键保持优先，无法序列化的值直接省略。 |
| 购物场景参数异常 | 无效覆盖值丢弃了正常 scene，抛错 getter 会中断整个入口快照，字符串 query 中的覆盖值又未生效；统一解析，隔离单字段错误并回退有效原始场景。 |

场景参数及冷热启动回退依据 [uni.getEnterOptionsSync 官方说明](https://uniapp.dcloud.net.cn/api/getEnterOptionsSync.html)；本轮仅补充原有方案的健壮性，不据此宣称设备验收完成。
